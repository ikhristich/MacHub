# MacHub

MacHub — нативная утилита для строки меню macOS. Она собирает повседневные инструменты в одной панели, которую можно открыть значком MacHub рядом с системными индикаторами.

- **Буфер обмена** сохраняет выбранные фрагменты для повторного использования. Сохранение запускается вручную.
- **System Pulse** показывает нагрузку на процессор, использование памяти, сетевую активность и состояние питания.
- **FlowState** позволяет сохранить раскладку панели и вручную запускать рабочие профили, которые открывают приложения, папки, документы и ссылки.

В MacHub также есть файловая полка Quick Drop и интерфейс Smart Converter. В этой публичной сборке добавление файлов на полку и запуск конвертации недоступны.

## Установка

Требуется Mac с Apple Silicon и macOS 27.0 или новее.

1. Скачайте `MacHub-0.1.0-26-arm64.dmg` из раздела [Releases](https://github.com/ikhristich/MacHub/releases).
2. Откройте образ и перетащите **MacHub.app** в папку **Applications**.
3. Запустите **MacHub** из папки «Программы» и найдите его значок в строке меню.

Сборка 0.1.0 (26) распространяется как предварительная версия с локальной подписью. У неё нет подписи Apple Developer ID и нотариального заверения Apple, поэтому Gatekeeper может заблокировать первый запуск. Сверьте SHA-256 скачанного образа с файлом `SHA256SUMS.txt` в релизе. Если вы доверяете источнику и хотите открыть приложение, используйте системные настройки «Конфиденциальность и безопасность». [Справка Apple](https://support.apple.com/ru-ru/102445)

О проблемах с установкой и работой приложения можно сообщить в [Issues](https://github.com/ikhristich/MacHub/issues).
