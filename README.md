# MacHub

MacHub — нативная утилита для строки меню macOS. Откройте её значком рядом с системными индикаторами, чтобы воспользоваться инструментами:

- **Буфер обмена** вручную сохраняет выбранные фрагменты для повторного использования.
- **Quick Drop** принимает файлы перетаскиванием на полку и помогает переносить их между приложениями. Выбранный угол открывает полку на любом подключённом мониторе.
- **Smart Converter** конвертирует изображения, аудио, видео и документы. Для входных и выходных файлов требуется локальный том APFS.
- **System Pulse** показывает нагрузку на процессор, использование памяти, сетевую активность и состояние питания.
- **FlowState** сохраняет раскладку панели и запускает рабочие профили, которые открывают приложения, папки, документы и ссылки.

## Установка

Требуется Mac с Apple Silicon и macOS 26.0 (Tahoe) или новее. Проверка запуска, полки и конвертера выполнена на macOS 27.0.1.

1. Скачайте `MacHub-0.1.0-29-arm64.dmg` из [релиза 0.1.0 (29)](https://github.com/ikhristich/MacHub/releases/tag/v0.1.0-build.29).
2. Откройте образ и перетащите **папку MacHub целиком** на ярлык **Applications**. В папке находятся приложение и файл проверки встроенного конвертера. Они должны лежать рядом.
3. Откройте **MacHub.app** из папки «Программы → MacHub». Значок MacHub появится в строке меню.

Если у вас уже есть предыдущая сборка, завершите её перед запуском новой. Данные MacHub хранятся отдельно от приложения.

У предварительной сборки нет подписи Apple Developer ID и нотариального заверения Apple. Если macOS заблокирует запуск, сверьте SHA-256 образа с `SHA256SUMS.txt` из релиза. Если вы доверяете источнику, воспользуйтесь системными настройками «Конфиденциальность и безопасность». [Справка Apple](https://support.apple.com/ru-ru/102445)

О проблемах с установкой и работой MacHub можно сообщить в [Issues](https://github.com/ikhristich/MacHub/issues).
